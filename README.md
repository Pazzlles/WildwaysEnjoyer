ФИО: Курышева Александра Александровна. 
Группа: Б9124-09.03.03пикд(3). 
Тема приложения: оффлайн-каталог треков группы Wildways для просмотра, поиска и сортировки по статусам. 
Кратко суть: приложение показывает список треков Wildways, позволяет искать по названию или статусу, фильтровать треки, открывать описание каждой песни, менять статус трека (Прослушать, Прослушано, Избранное) и смотреть текст песни.
